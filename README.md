# 麦麦营养搭配助手

一个基于麦当劳 MCP 的示例 Skill，可根据用户的用餐场景、口味和预算生成麦当劳餐品搭配建议。

## 主要功能

- 根据早餐、午餐、晚餐等场景推荐餐品
- 根据预算筛选套餐
- 展示推荐理由和预计价格
- 通过麦当劳 MCP 获取可用餐品信息

## 安装方法

1. 安装 Python 3.11 或更高版本。
2. 复制 `mcp-config.example.json` 并按实际环境填写环境变量。
3. 运行：

```bash
python main.py --scene 午餐 --budget 40
```

## 使用示例

```text
输入：午餐，预算 40 元，喜欢鸡肉
输出：推荐麦辣鸡腿堡套餐；满足鸡肉偏好，预计价格不超过 40 元。
```

## 目标用户

希望快速选择麦当劳餐品，以及对预算或口味有明确要求的消费者。

## 注意事项

本项目为比赛演示项目。餐品、价格和门店供应情况应以麦当劳 MCP 返回的实时数据为准。
